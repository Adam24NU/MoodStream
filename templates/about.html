About Moodify

A full-stack Flask app built around mood-driven music discovery.

What it does

Mood-Based Discovery

Select a mood and get five Spotify playlist recommendations pulled live from the Spotify API.

Mood History Dashboard

Every search is logged. Registered users can view a Chart.js dashboard of their mood patterns over time.

Personal Playlist Library

Save playlists you like and revisit them from your personal library at any time.

How it works

01

Pick a mood

Choose from Happy, Sad, Energetic, or Calm on the home page.

02

Spotify API query

Moodify builds a keyword search query and fetches matching playlists using the Spotify Web API's Client Credentials flow.

03

Explore & save

Browse the five results, open any playlist directly in Spotify, and save your favourites with one click.

Built with

Python 3 Flask 3 SQLAlchemy Flask-Login Spotipy Chart.js SQLite Vanilla JS
